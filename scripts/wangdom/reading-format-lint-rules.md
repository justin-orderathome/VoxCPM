# Reading Format Lint Rules (v1)

來源：`閱讀版.md`
目標：編譯 `語音版.json`

## 必備規則

1. 必須包含 `## 劇本` 章節
2. 至少一個幕標題：`【第X幕：幕名】`
3. 角色標頭行格式：
   - `{emoji} {角色名}（可選註記）：`
   - 或 `{角色名}：`
4. 每個角色標頭後必須有至少一行台詞
5. 舞台提示（`（...）`）不作為台詞

## 錯誤回報格式

- `L{line}: 角色標頭後無台詞內容`
- `L{line}: 未識別的角色標頭格式`
- `L{line}: 劇本區塊未找到有效對話段`

## 角色正規化

- `主公` -> `主公·劉邦`
- `諸葛亮` -> `軍師·諸葛亮`
- `李淳風` -> `司天監·李淳風`
- 其他依 `voice_profiles.yaml` 對照

## 指令互動

- `!drama -f/-s <資料夾名>`：若缺 `語音版.json`，先跑編譯
- 編譯失敗時回傳 lint 錯誤（含行號）
